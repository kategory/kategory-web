# kategory-web



Dies ist das Projekt, welches die Webseiten von kategory.de umsetzt.



Es handelt sich um "statische" Webinhalte, in dem Sinne, dass kein spezieller Server benötigt wird. Der Server muss nur

https unterstützen.



Genaugenommen wird das zunächst nur mit GitHub getestet, da wir zurzeit GitHub als Träger der Webseiten nutzen.
