# kategory-web

Dies ist das Projekt, welches die Webseiten von kategory.de umsetzt.

Es handelt sich um "statische" Webinhalte, in dem Sinne, dass kein spezieller Server benötigt wird. Der Server muss nur https unterstützen.

Zum Testen auf dem eigenen Rechner kann z.B. mit

   python -m http.server 8000

ein localer server gestartet werden und die Seite dann mit

   http://localhost:8000

aufgerufen werden.

Genaugenommen wird das zunächst nur mit GitHub getestet, da wir zurzeit GitHub als Träger der Webseiten nutzen.
